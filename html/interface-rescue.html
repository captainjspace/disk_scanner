Interface Rescue

Clearing Gateway Conflicts for TrendNet Recovery

Step 1: Clean Your Routing Table

Your Mac has 3 gateways. We need to kill the ones that aren't the TrendNet.

# 1. Turn off WiFi to stop the Orbi interference

networksetup -setairportpower en0 off

# 2. Delete the ghost gateway on en7

sudo route delete default 192.168.1.255

# 3. Force the route to the TrendNet UI

sudo route add -host 192.168.2.254 192.168.2.2

Step 2: TrendNet Internal Fix

Once you hit the UI at 192.168.2.254:

  • → Go to L2 Features > VLAN > 802.1Q
  • → Ensure VLAN 1 is still there.
  • → Ensure your Mac's port is an Untagged Member of VLAN 1.
  • → Change Management VLAN back to 1.
  • → Set Static IP back to 192.168.1.254.
